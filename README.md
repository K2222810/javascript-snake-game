# JavaScript Snake Game
A simple browser game where players control a snake, collect food, grow longer, and avoid crashing.

## Description
JavaScript Snake Game is a front-end project built with HTML, CSS, and JavaScript. The game lets players move a snake around a grid, collect apples, increase their score, and avoid hitting the wall or the snake’s own body.

The project was a good way to practice JavaScript game logic, DOM manipulation, keyboard controls, and updating the UI in real time. It also includes sound effects, a lives system, and high-score tracking using local storage.

## Planning
Before building, the focus was on the main gameplay features and how the game would work step by step.

Planning included:

- Writing user stories
- Mapping out snake movement and collision logic
- Planning the game board and UI
- Deciding how score, lives, and high score would work
- Breaking the game into smaller parts like grid setup, movement, food, and reset

## Brief
The goal of this project was to build a playable browser game using JavaScript, HTML, and CSS.

The game needed to show core JavaScript skills such as event handling, DOM updates, conditionals, timing functions, and game-state management.

## Build Process
The project started with building the grid and creating the snake on the board. After that, movement logic was added so the snake could move across the grid using keyboard controls.

Next, food placement, score updates, and collision detection were added. Once the core gameplay worked, extra features like lives, sound effects, reset functionality, and local-storage high-score tracking were included to make the game feel more complete.
